# ADR 0018: Structural OOD requires cue-to-action reversal

Status: accepted.

Severity extrapolation alone is insufficient. The revealed v1 pilot is development evidence and identifies same-mechanism ID/OOD pairs with close standardized public summaries but different oracle-optimal actions. Fresh hidden-v2 candidates must contain at least four non-overlapping reversals across at least two mechanisms within the frozen public-distance threshold. Generation aborts if that relationship-shift gate fails. Model responses never influence selection.
