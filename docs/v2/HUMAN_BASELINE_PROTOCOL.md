# Human baseline protocol (design only)

No human data are collected during v2 development.

If executed later, recruit participants with graduate-level economics, market-design, industrial-organization, or competition-policy training. Record expertise strata before exposure. Obtain ethics review or a documented exemption, informed consent, compensation terms, and a data-retention plan before recruitment.

Use the exact public observation, action descriptions, objective, horizon, and response schema used for models. Do not reveal latent families, simulator parameters, oracle values, baseline choices, or paired worlds. Randomize bundle order and action-display order while preserving action IDs. Give one independent decision per world; prohibit tools and feedback. Include comprehension checks that do not reveal optimal actions.

Freeze sample size through bundle-level precision analysis. Analyze human responses with the same intention-to-evaluate rules, paired bundle estimand, calibration measures, and multiplicity policy. Report recruitment, exclusions, compensation, missingness, expertise, and timing. Human results are a separate preregistered extension, not a post hoc benchmark embellishment.
