# Janus v2 comparative results

Status: outcome-free publication scaffold. Do not populate before all four response manifests are committed and the hidden set is unblinded under the frozen protocol.

## Abstract

State the paired public-policy comparison first. Separate decision loss from unavoidable information loss. Limit every claim to comparative behavior on Janus v2.

## Benchmark and preregistration

Describe the single market, four mechanisms, five actions, public observation contract, one-shot decision, twenty-period consequence horizon, sealed bundle construction, exact model versions, and pre-unblinding commit.

## Primary results

Report model utility minus frozen public-policy utility with bundle-clustered intervals for all four models. Report six paired model contrasts with raw and Holm-adjusted p-values. Do not count worlds, replicates, or models as independent bundles.

## Loss decomposition

For each model report oracle-minus-public information loss, public-minus-model decision loss, and their sum (full-information regret). Add worst-decile regret and ID/OOD differences.

## Hierarchical analysis

Report the REML fixed effects, bundle/world/replicate variance components, model-by-mechanism and model-by-OOD interactions, convergence diagnostics, and deterministic variance cross-check. Treat provider-family marginals descriptively because Anthropic and Google each contribute only one model.
