# Reports

This directory contains frozen research reports and deterministic publication outputs.

Path | Contents
--- | ---
`v2-publication/` | Public Janus v2 tables, figures, hashes, and source-report manifest
`v2/` | Prospective gates, precision analysis, matched contrasts, and report template
`hidden-v1-publication/` | Frozen v1 publication tables and figures
`hidden-v1-results.md` | v1 result narrative and limitations
`readiness.md` | Release evidence and exact local commands

Regenerate the v2 public outputs with:

```bash
uv run janus v2-publication
```

Local article drafts are intentionally excluded from version control.
